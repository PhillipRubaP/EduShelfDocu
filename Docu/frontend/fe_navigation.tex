\section{Navigationsstruktur und Layout (MainLayout.jsx)}

Die Navigation erfolgtg durch die Komponente \texttt{MainLayout.jsx}. Sie stellt sicher, dass die Navigationsleiste stets sichtbar bleibt, während sich der Inhaltsbereich dynamisch verändert.

\subsection{Outlet-Pattern und verschachtelte Routen}

Das Layout nutzt das \texttt{<Outlet />}-Konzept von React Router. Dieses Schema erlaubt es, die Navigationsleiste und den Inhaltsbereich strikt voneinander zu trennen: Das Layout wird einmal gerendert und bleibt dann, während React Router die jeweils aktive Child-Komponente an der \texttt{<Outlet />}-Stelle einfügt. Dadurch wird unnötiges Re-Rendern vermieden und die Performance optimiert.

\begin{lstlisting}[language=JavaScript, caption={Outlet-Pattern in MainLayout.jsx}]
const MainLayout = ({ handleLogout, user }) => {
  return (
    <div className="app-container">
      <header className="navbar">
        {/* Navigationsleiste -- wird nie neu gerendert */}
        <nav className="navbar-nav">
          <NavLink to="/">Dashboard</NavLink>
          <NavLink to="/files">Files</NavLink>
          {/* ... */}
        </nav>
      </header>
      <main className="main-content">
        <Outlet /> {/* Hier wird die aktive Seite eingefuegt */}
      </main>
    </div>
  );
};
\end{lstlisting}

\subsection{Rollenbasierte Navigation (RBAC)}

Die Sichtbarkeit des Menüpunkts \textit{Admin Panel} wird direkt in der \texttt{MainLayout.jsx}--Komponente gesteuert. Eine Abfrage überprüft, ob das übergebene \texttt{user}-Objekt die Rolle \texttt{'Admin'} im enthält:

\begin{lstlisting}[language=JavaScript, caption={Rollenbasierte Anzeige des Admin-Menüpunkts}]
{user && user.roles && user.roles.includes('Admin') && (
  <NavLink to="/admin">Admin Panel</NavLink>
)}
\end{lstlisting}

Diese Überprüfung findet ausschließlich clientseitig statt und dient dazu zu vermeiden, dass Benutzer unerwünschterweise Rechte erlangen, die sie eigentlich nicht haben sollten. Die eigentliche Zugriffskontrolle auf admin-spezifische API-Endpunkte erfolgt allerdings serverseitig, sodass ein manuelles Manipulieren der URL durch den Nutzer keine sicherheitsrelevanten Auswirkungen hat.

\subsection{Aktiver Zustand mit NavLink}

React Router stellt die Komponente \texttt{NavLink} bereit, welche gegenüber dem einfachen \texttt{Link} den Vorteil bietet, den aktuell aktiven Zustand zu kennen. Über eine Callback-Function kann die CSS-Klasse des Elements dynamisch gesetzt werden:

\begin{lstlisting}[language=JavaScript, caption={Dynamische CSS-Klasse bei aktivem Navigationselement}]
<NavLink
  to="/files"
  className={({ isActive }) => (isActive ? 'active' : '')}
>
  Files
</NavLink>
\end{lstlisting}

Der Parameter \texttt{isActive} wird von React Router automatisch auf \texttt{true} gesetzt, wenn die aktuelle URL mit dem \texttt{to}-Attribut des Links übereinstimmt. Die CSS-Klasse \texttt{active} hebt den aktuell ausgewählten Menüpunkt visuell hervor und verbessert so die UX, da man immer genau erkennen kann wo man sich aktuell befindet.
