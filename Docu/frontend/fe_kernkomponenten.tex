\section{Implementierung der Kernkomponenten}

Dieses Kapitel gibt einen Überblick über die zentralen Komponenten von EduShelf. Jede Komponente ist als eigenständige \texttt{.jsx}-Datei realisiert und über React Router als eigene Route erreichbar. Die detaillierte Betrachtung der Tabs -- Dateiverwaltung, Quiz, Lernkarten, Chat, Admin und Profil -- erfolgt in den nachfolgenden Abschnitten.
